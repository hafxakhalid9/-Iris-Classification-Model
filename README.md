# Iris Flower Classification Model

A basic machine learning classification project built using Python, Scikit-Learn, and Google Colab.

##  Project Overview
This project uses supervised learning to classify Iris flower species (`setosa`, `versicolor`, or `virginica`) based on four physical features:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

##  Key Steps Completed
1. **Data Loading:** Loaded the Iris dataset directly via `scikit-learn`.
2. **Data Splitting:** Separated the dataset into training (80%) and testing (20%) sets.
3. **Model Training:** Trained a Logistic Regression classification model.
4. **Evaluation:** Evaluated accuracy and generated a classification report on unseen test data.
